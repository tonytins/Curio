# 🖼️ Curio

This is a simple gallery-dl GUI for macOS, Windows, and Linux made using SwiftCrossUI.

## 🖥️ Supported Platforms

| Platform | Minimum Version |
| --- | --- |
| macOS | 13+ |
| Windows | 10+ |
| Linux | gtk 3+ |

## 🔨 Building

```
swift-bundle run
```
